# AGENTS.md

## 项目设计哲学
本项目在前端界面中融合两种高度互补的设计语言：
- **Liquid Glass（液态玻璃）**：视觉上以多层半透明材质、流体形态与动态光影模拟真实玻璃质感，营造轻盈、深邃且富有科技感的界面。
- **Apple’s Restrained Aesthetics（苹果克制美学）**：以内容为中心，通过极致的留白、克制的色彩、精准的动效和一致的层次来表达信息，去除一切不必要的装饰。

两者共同指导我们的 Web 前端设计：让界面像一块通透的液态玻璃，但始终保持安静、优雅，永远服务于内容。

## 一、Liquid Glass 设计风格核心特征

### 1. 多层次半透明与模糊
- **背景模糊**：使用 `backdrop-filter: blur()` 在元素下层生成逼真的玻璃质感，而非简单透明度。
- **饱和度增强**：模糊时通常配合 `saturate()` 提升色彩鲜活度，模拟玻璃折射效果。
- **多层叠加**：通过不同模糊值与透明度的卡片、导航、模态层叠，构建空间纵深感。

### 2. 流体与有机形态
- **连续曲率圆角**：采用超椭圆（squircle）或高缓动贝塞尔圆角，避免生硬的普通圆角。Web 中可用较大 `border-radius` 或借助 `clip-path`、`mask` 实现类连续曲率。
- **流动渐变与虹彩**：背景色使用多色阶渐变，并通过模糊层间的交融形成“流动”的液体光泽。
- **自然的不规则形状**：可适度使用流体玻璃形状（如 SVG 波浪、平滑 blob）作为装饰背景，保持轻量且不干扰内容。

### 3. 玻璃材质光影
- **边缘高光**：用细的半透明白色内/外边框 (`border: 1px solid rgba(255,255,255,0.3)`) 表现玻璃厚度与边缘折射。
- **柔和投影**：多层阴影，近距淡阴影 + 远距弥散阴影，避免生硬黑色投影。
- **光晕与噪点**（进阶）：极少量使用渐变光晕或 subtle noise 纹理强化玻璃真实感。

### 4. 动态响应光感
- **视差与鼠标跟随**：玻璃卡片可随鼠标位置轻微移动，并改变高光角度，模拟真实玻璃的折光变化（仅用于关键视觉区域，非全局）。
- **环境光适应**：卡片/组件半透明背景应能透出下方色彩，形成“感知环境”的视觉融合。

### 5. 色彩方案
- **底色**：以浅色/深色中性灰白为基底，内容区保留纯白或极深灰以保持可读性。
- **玻璃层色彩**：使用 `rgba(255,255,255,0.15-0.25)` 或深色模式下 `rgba(0,0,0,0.2-0.4)`。
- **强调色**：通过苹果系统色彩体系（如 System Blue, Pink, Teal）点缀，保持纯净，避免过度饱和。

## 二、苹果克制设计美学核心原则

### 1. 清晰（Clarity）
- 文字始终清晰可读，字号层级明确，行距宽松。
- 图标精准达意，不使用歧义或过度装饰的图形。
- 界面的每个元素都应有明确的意图。

### 2. 遵从（Deference）
- UI 永远作为内容的背景：利用半透明、模糊、细线边框等轻量手法区分层级，而不抢夺视线。
- 大量留白，让内容和功能模块自然呼吸。
- 导航和装饰元素尽可能缩小、隐藏，直到需要时展现。

### 3. 深度（Depth）
- 通过 z 轴分层、模糊、投影、缩放营造自然层级，但不依赖沉重阴影。
- 模态、弹出层使用放大与模糊过渡，让用户感受到物理空间关系。

### 4. 一致（Consistency）
- 统一的设计令牌：间距、圆角半径、字体比例、阴影参数、动效曲线全部标准化。
- 组件行为、反馈、手势在所有视图间保持可预测。

### 5. 直接操控与反馈
- 交互动效模仿真实物理：滚动带惯性，点击有轻触反馈（缩放或高亮），转场平滑连续。
- 动效服从功能，不使用炫技式动画。标准缓动曲线 `cubic-bezier(0.25, 0.1, 0.25, 1)` 和弹簧动效。

### 6. 克制的色彩与排版
- 主色使用平台系统色（与操作系统一致的蓝、绿、粉等），辅以极淡的灰度层次。
- 字体家族首选系统无衬线体（如 `-apple-system, SF Pro Text, Inter`），字重变化仅用 Regular、Medium、Semibold，避免额外装饰。
- 极少的色彩种类，全页面通常不超过 3 种强调色。

### 7. 内容至上与精简
- 能用一个词表达的不用一句话；能用留白区分的不用线条分割。
- 图标与按钮尽量使用“无边框”样式，仅通过透明度和位置表达交互态。

## 三、Web 前端实现指引（Liquid Glass + Apple Aesthetics）

### 设计令牌（CSS Custom Properties）
```css
:root {
  /* 玻璃底层色调 */
  --glass-bg-light: rgba(255, 255, 255, 0.2);
  --glass-bg-dark: rgba(0, 0, 0, 0.25);
  --glass-blur: blur(20px) saturate(180%);
  
  /* 边框与高光 */
  --glass-border: 1px solid rgba(255, 255, 255, 0.3);
  --glass-border-subtle: 1px solid rgba(255, 255, 255, 0.1);
  
  /* 阴影层次 */
  --shadow-glass-sm: 0 2px 8px rgba(0,0,0,0.05), 0 0 0 0.5px rgba(255,255,255,0.6);
  --shadow-glass-md: 0 8px 32px rgba(0,0,0,0.08), 0 0 0 1px rgba(255,255,255,0.4);
  
  /* 圆角系统 */
  --radius-sm: 8px;
  --radius-md: 16px;
  --radius-lg: 24px;
  --radius-xl: 32px;   /* 接近超椭圆效果 */
  
  /* 动效曲线 */
  --ease-apple: cubic-bezier(0.25, 0.1, 0.25, 1);
  --spring: cubic-bezier(0.34, 1.56, 0.64, 1);
}
